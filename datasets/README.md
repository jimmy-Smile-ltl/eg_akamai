# datasets/ — 公开数据集

只放**来源可核对、可以公开**的数据集。扫描得到的站点清单、逐站判定和会话
材料不属于这里（见 [BOUNDARIES §6](../docs/BOUNDARIES.md#6-数据政策)）。

| 数据集 | 内容 | 规模 | 来源 | 入口 |
|---|---|---|---|---|
| [`akamai_customers/`](akamai_customers/) | akamai.com 官网公开客户案例索引 | 304 条案例 / 273 条网址 / 268 个主机 | akamai.com 两个公开列表页（2026-09-17 快照） | [README](akamai_customers/README.md) |

## `akamai_customers/` 里有什么

| 文件 | 说明 |
|---|---|
| `stories.csv` | 一条案例一行：中英文标题、行业、地点、客户网址 |
| `sites.csv` | 按主机名去重，合并同一主机的多条案例 |
| `collect.py` | 重新采集脚本（`curl_cffi` + `beautifulsoup4`） |
| `check_akamai.py` | 可选检测：这批站现在是否还有 Akamai 信号 |
| `README.md` | 字段、口径、复现方式、这份清单"不是什么" |

## 两条边界

- **它回答"官网公开列过谁"，不是"谁现在还在用 Akamai"**：案例会长期保留，
  客户可能已经迁移；2026-09-17 首页级检测里，273 条网址只有 100 条仍有信号。
- **逐站检测结果不提交**：`akamai_check.*` 已被 `.gitignore` 排除。仓库只发
  来源清单，不发扫描结论。

## 新增数据集的规则

1. 来源必须是公开页面或公开数据，且允许再分发；
2. 只收事实性元数据，不收正文、图片、联系方式；
3. 附可复现的采集脚本与快照时间；
4. 在 README 里写清"不是什么"，避免被当成实时名录；
5. 运行产物（逐站检测、临时目录）加入 `.gitignore`。
